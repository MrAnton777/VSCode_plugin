# Lab Project Checker

Расширение VS Code для проверки проекта перед сдачей лабораторной работы.

## Текущее состояние

Подготовлен минимальный каркас на JavaScript. Команда выбирает открытый проект и показывает сообщение о запуске расширения. Сами проверки пока не реализованы.

Запланированы проверки обязательных файлов и папок, содержимого файлов и игнорирования путей Git.

## Запуск

1. Открыть папку `lab_3` в VS Code.
2. Нажать F5 — откроется окно Extension Development Host.
3. В новом окне открыть папку проекта для проверки.
4. Открыть палитру команд: `Ctrl+Shift+P` или `Cmd+Shift+P`.
5. Выполнить `Lab Project Checker: Проверить проект`.

Установка зависимостей и компиляция не нужны.

## Структура

```text
package.json        — описание, команда и настройки расширения
extension.js        — логика и интерфейс
README.md           — инструкция
.vscode/launch.json — запуск через F5
```

## Настройки

В настройках VS Code зарегистрированы три списка требований, пока пустые:

- `labProjectChecker.requiredFiles` — обязательные файлы и папки;
- `labProjectChecker.requiredContent` — пары `file` и `text` для проверки содержимого;
- `labProjectChecker.ignoredPaths` — пути, которые должны игнорироваться Git.

Они будут использоваться при реализации проверок.
