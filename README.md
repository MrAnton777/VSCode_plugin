# Daylight Profiles

Расширение VS Code для управления оформлением редактора по времени суток и пользовательским профилям.

## Текущее состояние

Минимальный каркас на JavaScript: команда проверяет запуск расширения и показывает сообщение. Переключение тем, профили и расписание ещё не реализованы.

## Планируемые функции

Выбраны пункты 1, 2, 4, 5, 6 и 7 рекомендаций преподавателя:

- Настраиваемое расписание переключения профилей.
- Профили с темой оформления, размером шрифта и высотой строки.
- Интерфейс управления профилями и расписанием.
- Ручное переключение через команду и кнопку в строке состояния.
- Приоритет ручного выбора до явного возврата в автоматический режим.
- Сохранение настроек и ручного выбора после перезапуска VS Code.

## Запуск

1. Открыть папку `lab_3` в VS Code.
2. Нажать F5 — откроется отдельное окно Extension Development Host.
3. В новом окне открыть палитру команд: `Ctrl+Shift+P` или `Cmd+Shift+P`.
4. Выполнить `Daylight Profiles: Проверить запуск`.
5. Должно появиться сообщение о запуске расширения.

Установка зависимостей, компиляция и установка расширения не нужны.

## Структура

```text
package.json        — описание расширения и регистрация команды
extension.js        — точка входа и обработчик команды
README.md           — инструкция и планируемые функции
.vscode/launch.json — запуск через F5
```

Проверка синтаксиса: `npm run check`.
